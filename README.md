# Dance Realm

Connecting Dancers Worldwide.

Dance Realm is a modern, responsive web application built with Next.js, React, and Tailwind CSS, designed to connect the global dance community.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Components**: Radix UI / ShadCN
- **Icons**: Lucide React
- **Animations**: Tailwind Animate / Framer Motion patterns

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.

## How to Push to GitHub

To push this code to your GitHub repository, follow these steps:

1. **Create a new repository** on GitHub.
2. **Open your terminal** in the root of this project.
3. **Initialize the local directory** as a Git repository:
   ```bash
   git init
   ```
4. **Add the files** in your new local repository:
   ```bash
   git add .
   ```
5. **Commit the files** that you've staged in your local repository:
   ```bash
   git commit -m "Initial commit of Dance Realm"
   ```
6. **Add the URL** for the remote repository where your local repository will be pushed:
   ```bash
   git remote add origin <YOUR_GITHUB_REPO_URL>
   ```
7. **Push the changes** in your local repository to GitHub:
   ```bash
   git push -u origin main
   ```
